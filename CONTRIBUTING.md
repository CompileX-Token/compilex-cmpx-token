# Contributing

CompileX is currently in an early testnet phase.

## Guidelines

- Do not submit private keys, seed phrases or `.env` files.
- Keep changes simple and auditable.
- Add tests for contract-level changes.
- Avoid hype, price claims or investment wording.
- Clearly mark anything that is testnet-only.

## Local Workflow

```bash
npm install
npm test
npm run compile
```
