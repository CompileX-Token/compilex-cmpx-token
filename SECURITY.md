# Security Policy

## Supported Status

CompileX is currently an experimental Sepolia testnet project.

## Reporting Security Issues

If you discover a potential security issue, do not open a public issue with exploitable details. Contact the maintainer privately first.

Contact:

```text
[security contact email]
```

## Scope

In scope:

- CompileXToken smart contract,
- deployment scripts,
- testnet payment demo documentation.

Out of scope:

- third-party wallet behavior,
- third-party RPC providers,
- Sepolia testnet reliability,
- Etherscan availability.

## Mainnet Notice

CompileX is not mainnet-ready until it has gone through extended review, audit preparation and legal/tax review.
