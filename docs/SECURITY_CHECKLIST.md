# Security Checklist

## Niemals veröffentlichen

- `.env`
- Private Keys
- Seed Phrases
- echte RPC Keys, falls nicht öffentlich gedacht
- persönliche Wallet-Backups
- `node_modules/`
- Hardhat `artifacts/` und `cache/`

## Vor Mainnet

- Tests erweitern
- Static Analysis prüfen
- externe Review/Audit vorbereiten
- Treasury-Wallets definieren
- Multisig-Setup prüfen
- Token-Verteilung transparent dokumentieren
- rechtliche und steuerliche Prüfung abschließen

## Aktueller Status

CompileX ist aktuell ein Sepolia-Testnet-Projekt. Mainnet ist nicht gestartet.
